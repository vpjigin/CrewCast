# Security Policy

## Supported versions

Security fixes are provided for the **latest release** only. Older releases are not supported.

## Reporting a vulnerability

Please report security issues **privately** — do not open a public GitHub issue.

- **Preferred:** Use [GitHub’s private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) for this repository (**Security** tab → **Report a vulnerability**).
- **Alternative:** Email [solocrew.me@gmail.com](mailto:solocrew.me@gmail.com).

## What to include

To help us investigate, please include:

- Crewcast **version** (release tag or commit, if known)
- **Operating system** and architecture
- Clear **steps to reproduce** the issue
- Impact assessment if you can (what an attacker could do)

## What to expect

We aim to **acknowledge** your report within a few days. We cannot commit to fixed timelines for analysis or patches; progress depends on severity and complexity.

Thank you for helping keep Crewcast users safe.
